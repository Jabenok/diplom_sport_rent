# 🏅 СПОРТ-ПРОКАТ

Веб-приложение для аренды спортивного инвентаря, построенное на Flask. Позволяет пользователям просматривать доступный инвентарь, оформлять аренду с выбором времени, управлять своим профилем, а администраторам — управлять каталогом оборудования и категориями.

---

## Возможности

**Для пользователей**
- Регистрация и авторизация
- Просмотр каталога инвентаря с фильтрацией по названию, категории и статусу, сортировкой и пагинацией
- Оформление аренды с выбором даты и времени начала/окончания, автоматическим расчётом стоимости
- Продление активной аренды
- Возврат инвентаря с итоговым расчётом оплаты
- Личный кабинет с историей аренд и редактированием профиля
- Хранение паспортных данных в хэшированном виде (через Werkzeug)

**Для администраторов**
- Добавление, редактирование и удаление позиций инвентаря
- Управление категориями (создание, переименование, удаление)
- Ручной возврат инвентаря

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your-username/sport-prokat.git
cd sport-prokat
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настроить базу данных

Создайте базу данных MySQL:

```sql
CREATE DATABASE rentdb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

При необходимости отредактируйте строку подключения в `config.py`:

```python
SQLALCHEMY_DATABASE_URI = 'mysql+pymysql://root:@localhost/rentdb'
```

### 4. Запустить приложение

```bash
python run.py
```

Таблицы создаются автоматически при первом запуске. Приложение будет доступно по адресу `http://localhost:5000`.

### Создание администратора

Установить флаг `is_admin = True` для нужного пользователя напрямую в БД:

```sql
UPDATE user SET is_admin = 1 WHERE email = 'your@email.com';
```

## Тесты

Тесты используют SQLite in-memory — MySQL для их запуска не нужен.

```bash
pytest
```

Или с подробным выводом:

```bash
pytest -v
```

Тестовое покрытие включает:
- Регистрацию и авторизацию
- Права доступа (403 для не-администраторов)
- CRUD инвентаря через админ-панель
- Валидацию дат при аренде
- Хэширование паспортных данных (хранение, проверку, сброс, уникальность соли)

---

## Безопасность

- Пароли хэшируются через `werkzeug.security.generate_password_hash`
- Паспортные данные также хранятся только в виде хэша — восстановить их из БД невозможно
- Все маршруты администратора защищены декоратором `@admin_required`
- Пользователь может вернуть или продлить только свою аренду
